
# Web Application Penetration Testing

## Description
This project provides a controlled environment for practicing penetration testing on web applications. It serves as a tool for identifying and analyzing common security vulnerabilities, including SQL Injection, Cross-Site Scripting (XSS), and Cross-Site Request Forgery (CSRF).

## Features
- **SQL Injection Testing:** Automated scripts to detect database query manipulation vulnerabilities (`sql_injection_test.py`).
- **XSS Simulation:** Testing modules to identify stored and reflected Cross-Site Scripting flaws (`xss_test.py`).
- **CSRF Vulnerability Assessment:** Verification scripts to test for insecure state-changing requests (`csrf_test.py`).
- **Modular Architecture:** A centralized execution flow managed by `main.py` for streamlined testing.

## Technologies
- **Language:** Python
- **Libraries:** Requests

## Learning Objectives
- Master the fundamentals of web application security testing.
- Develop hands-on experience in identifying, documenting, and mitigating critical vulnerabilities in a sandbox environment.
