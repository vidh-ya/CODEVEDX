
# 🔐 CODEVEDX – Cybersecurity Projects

## 📌 Overview
This repository contains three Python-based projects focused on **password security** and **web application penetration testing**.  
It is designed for **educational purposes** to understand vulnerabilities, strengthen authentication, and practice ethical hacking concepts.

---

## 🛡️ Projects Included (Sorted)

### 1️⃣ Password Security & Cracking Analysis
- **Description:** Evaluates password strength and demonstrates how weak passwords can be cracked using simple techniques.  
- **Features:**
  - Password Strength Checker
  - Strong Password Generator
  - Dictionary Attack Simulation
  - Brute Force Attack Simulation
- **Technologies:** Python, Regex, Random library  
-
Learning Outcome: Understand password vulnerabilities and importance of strong authentication.

2️⃣ Vulnerability Scanner
Description: A Python tool to scan web applications for common vulnerabilities.

Features:

Detects SQL Injection (SQLi)

Identifies Cross-Site Scripting (XSS)

Checks for CSRF issues

Generates detailed reports in results/ folder

Technologies: Python, Requests library, Regex


3️⃣ Web Application Penetration Testing
Description: Simulates penetration testing on sample web applications.

Features:

SQL Injection test cases (sql_injection_test.py)

XSS attack simulation (xss_test.py)

CSRF vulnerability testing (csrf_test.py)

Technologies: Python, Requests library




🔐 Learning Goals
Strengthen understanding of password security

Explore vulnerability scanning techniques

Practice penetration testing on sample applications

Build portfolio-ready projects for internships

⚠️ Disclaimer: These projects are for educational purposes only. Do not use attack simulations on real systems.
